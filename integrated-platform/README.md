# 🚀 پلتفرم جامع هوش مصنوعی و خدمات دیجیتال

## 🧠 تئوری و معماری
این سیستم یک **پلتفرم یکپارچه** است که تمام پروژه‌های موجود را در قالب **میکروسرویس‌های مستقل** گرد هم آورده است. معماری آن بر پایه‌ی **Gateway Pattern** طراحی شده که تمام درخواست‌ها را دریافت و به سرویس‌های مربوطه هدایت می‌کند.

## 🏗️ اجزای سیستم
| سرویس | پورت | توضیح |
|--------|------|--------|
| Gateway | 8080 | دروازه‌ی اصلی |
| 3D Conversion | 3001 | تبدیل 2D به 3D |
| NLP Engine | 3002 | پردازش زبان طبیعی |
| Shop | 3003 | فروشگاه آنلاین |
| Admin Dashboard | 3004 | مدیریت و نظارت |
| Chess Engine | 3005 | شطرنج با AI |
| Olympic Games | 3006 | بازی‌های المپیک |
| AI Project Manager | 3007 | مدیریت پروژه |
| Probability Tools | 3008 | ابزارهای احتمالات |

## 🚀 اجرا
```bash
cd integrated-platform
./scripts/start-all.sh
```

سپس در مرورگر: http://localhost:8080

🔧 توسعه

هر سرویس به‌صورت مستقل قابل توسعه است. برای اضافه کردن سرویس جدید:

1. پوشه‌ی آن را در services/ ایجاد کنید.
2. در gateway/server.js به SERVICES اضافه کنید.
3. در frontend/app.js به SERVICES اضافه کنید.

📚 مستندات بیشتر

برای اطلاعات بیشتر به مخزن اصلی مراجعه کنید.
