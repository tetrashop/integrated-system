# Tetrashop Sample Repository 🚀

## نمونه مخزن کامل با ۳ پروژه اجراشدنی

### 🎯 پروژه‌ها

1. **📈 Dashboard** - داشبورد مدیریت با داده‌های زنده
2. **🛍️ Store** - فروشگاه آنلاین با سبد خرید
3. **🤖 Analytics** - تحلیل شبکه‌های اجتماعی

### 🚀 راه‌اندازی

```bash
cd /data/data/com.termux/files/home/tetrashop-final-sample
npm install
npm start
```

### 🌐 آدرس‌ها

- اصلی: http://localhost:3000
- API وضعیت: http://localhost:3000/api/status
- داشبورد: http://localhost:3000/projects/dashboard/
- فروشگاه: http://localhost:3000/projects/store/
- تحلیل: http://localhost:3000/projects/analytics/
