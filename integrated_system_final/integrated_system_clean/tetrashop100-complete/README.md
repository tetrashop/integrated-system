# Tetrashop100 - سامانه جامع مدیریت فروش، تبدیل سه‌بعدی و پرداخت ارز دیجیتال

Tetrashop100 یک پروژه‌ی متن‌باز و آماده‌ی دیپلوی است که مجموعه‌ای از ابزارهای مدرن کسب‌وکار دیجیتال را یکجا در اختیار شما قرار می‌دهد. از فروشگاه و پنل مدیریت گرفته تا تبدیل تصاویر دوبعدی به مدل‌های سه‌بعدی و پذیرش پرداخت‌های ارز دیجیتال، همه در یک بسته‌ی سبک، بدون نیاز به سرور پیچیده، قابل اجرا روی مرورگر و دیپلوی فوری.

## ✨ ویژگی‌های کلیدی

- **فروشگاه آنلاین** – مدیریت محصولات، سبد خرید و سفارشات
- **پنل مدیریت** – کنترل کامل کاربران، فروش، محتوا و تنظیمات
- **داشبورد کاربری** – پروفایل، تاریخچه سفارشات و کیف‌پول
- **تبدیل 2D به 3D** – آپلود تصویر و دریافت یک مدل سه‌بعدی ابتدایی (مبتنی بر Three.js)
- **مدیریت ارزهای دیجیتال** – پشتیبانی از بیت‌کوین، اتریوم، تتر و سایر ارزها برای پرداخت
- **مدیریت مالی** – گزارش درآمد، تراکنش‌ها و موجودی
- **احراز هویت** – ورود/ثبت‌نام کاربران (قابل اتصال به بک‌اند یا حالت دمو)
- **طراحی واکنش‌گرا** – نمایش عالی در موبایل، تبلت و دسکتاپ
- **یک‌پارچه‌سازی آسان** – فایل‌های استاتیک که روی هر هاست یا CDN قابل اجراست
- **پشتیبانی از دیپلوی فوری** – تنظیمات آماده برای Netlify، Vercel و سایر پلتفرم‌ها

## ⚙️ پیش‌نیازها و راه‌اندازی محلی

برای اجرای پروژه روی سیستم خود نیازی به Node.js یا پیش‌نیاز خاصی نیست.  
کافی است یک مرورگر مدرن داشته باشید.

### اجرای مستقیم

1. ریپازیتوری را کلون کنید:
```bash
git clone https://github.com/tetrashop/tetrashop100-complete.git
cd tetrashop100-complete
```

1. فایل index.html را مستقیماً در مرورگر باز کنید،
   یا از یک سرور استاتیک ساده استفاده کنید:

```bash
npx serve .
```

سپس مرورگر را روی آدرس http://localhost:3000 باز کنید.

توجه

· پنل‌های جداگانه از طریق مسیرهایی مانند /admin, /dashboard, /shop قابل دسترسی هستند.
· در نسخه‌ی فعلی، برخی از این مسیرها به همان index.html ریدایرکت می‌شوند تا UI اصلی بارگذاری شود. برای توسعه‌ی صفحات اختصاصی، می‌توانید محتوای هر پوشه را ویرایش کنید.

🚀 دیپلوی (Deploy)

پروژه کاملاً استاتیک است و روی هر سرویس میزبانی فایل‌های HTML/CSS/JS قابل اجراست.
تنظیمات مخصوص دو پلتفرم محبوب از پیش آماده شده‌اند:

Netlify

1. یک سایت جدید از روی ریپازیتوری Git ایجاد کنید.
2. دستور Build را خالی بگذارید.
3. پوشه‌ی انتشار (Publish directory) را روی . تنظیم کنید.
4. فایل netlify.toml موجود ریدایرکت‌های لازم را انجام می‌دهد.

Vercel

1. ریپازیتوری را در Vercel ایمپورت کنید.
2. Framework Preset را روی Other بگذارید.
3. Output Directory را خالی بگذارید (ریشه‌ی پروژه).
4. تنظیمات vercel.json به‌طور خودکار مسیرها را مدیریت می‌کند.

سایر پلتفرم‌ها (GitHub Pages, Firebase, ...)

· کافی است کل محتوای ریپازیتوری را روی شاخه‌ی انتشار (مثلاً gh-pages یا public) قرار دهید.
· در صورت نیاز به ریدایرکت، فایل‌های معادل آن پلتفرم را ایجاد کنید (مثلاً _redirects برای Netlify یا firebase.json).

🔧 رفع باگ‌ها و بهینه‌سازی‌های انجام‌شده

در این نسخه (پس از کلون اولیه) چند مشکل عمده که مانع دیپلوی یا اجرای درست می‌شد برطرف شده است:

· اصلاح مسیرهای چک‌شدن در deploy.js
    اسکریپت بررسی فایل‌های ضروری را به‌روز کرده تا با ساختار واقعی پروژه مطابقت داشته باشد.
· تکمیل ریدایرکت‌ها در netlify.toml و vercel.json
    مسیرهای /admin, /dashboard, /shop که در لینک‌های UI وجود داشتند ولی ریدایرکت نشده بودند، اکنون به درستی به index.html هدایت می‌شوند تا خطای 404 ندهند.
· پاک‌سازی و آماده‌سازی برای دیپلوی بدون خطا

🧩 بخش‌های مختلف پروژه

🛒 فروشگاه (Shop)

· نمایش محصولات با قیمت و توضیحات
· سبد خرید ساده

· نمایش اطلاعات کاربر
· سفارشات اخیر
· موجودی کیف پول داخلی (نمونه)

🔐 پنل مدیریت

· مدیریت کاربران
· مدیریت محصولات
· مشاهده‌ی تراکنش‌ها و گزارش‌ها

🪙 مدیریت ارزهای دیجیتال

· نمایش قیمت‌های لحظه‌ای (در نسخه‌ی دمو از داده‌های شبیه‌سازی‌شده استفاده می‌کند)
· امکان انتخاب ارز برای پرداخت
· تاریخچه‌ی تراکنش‌های کریپتو

🧊 تبدیل 2D به 3D

· بارگذاری یک تصویر
· ایجاد یک صفحه/کره‌ی سه‌بعدی با بافت تصویر (با Three.js)
· چرخش و بزرگنمایی مدل

🛠 توسعه و سفارشی‌سازی

پروژه صرفاً با HTML، CSS و JavaScript خالص نوشته شده و وابستگی خارجی حداقلی دارد.
برای افزودن امکانات جدید:

1. صفحات جدید: یک فایل HTML در مسیر مورد نظر بسازید و ریدایرکت‌های لازم را در netlify.toml یا vercel.json اضافه کنید.
2. ظاهر و تم: فایل‌های CSS درون هر پوشه یا index.html اصلی را ویرایش کنید.
3. ارتباط با بک‌اند: فراخوانی‌های fetch به API واقعی را جایگزین داده‌های شبیه‌سازی‌شده (mock) کنید.
4. افزودن کتابخانه: از CDN برای کتابخانه‌های اضافی استفاده کنید (پروژه در حال حاضر از Three.js برای 3D استفاده می‌کند).
