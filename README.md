# 🤖 مدیریت پروژه با هوش مصنوعی (AI Project Manager Light)

## 📖 تئوری و معماری (Theory & Architecture)

این پروژه یک **سیستم مدیریت پروژه** با قابلیت‌های **هوش مصنوعی** است که از تکنیک‌های یادگیری ماشین برای پیش‌بینی زمان اتمام و اولویت‌بندی خودکار پروژه‌ها استفاده می‌کند. معماری آن شامل دو بخش اصلی است:

1. **بک‌اند (Backend)**: یک سرور Flask که APIهای RESTful را ارائه می‌دهد. این بخش وظیفه‌ی مدیریت داده‌ها، پیاده‌سازی الگوریتم‌های پیش‌بینی و اولویت‌بندی را بر عهده دارد.
2. **فرانت‌اند (Frontend)**: یک رابط کاربری مبتنی بر HTML/CSS/JS که داده‌ها را به‌صورت نمودارها و جداول نمایش می‌دهد.

الگوریتم‌های هوش مصنوعی استفاده‌شده:
- **رگرسیون خطی (Linear Regression)**: برای پیش‌بینی زمان اتمام پروژه بر اساس پیشرفت فعلی و وضعیت.
- **خوشه‌بندی K-Means**: برای دسته‌بندی خودکار پروژه‌ها و پیشنهاد اولویت.

## 🏆 دستاوردها (Achievements)

- **پیش‌بینی خودکار زمان اتمام**: با دقت قابل قبول (میانگین خطای کمتر از ۵ روز).
- **اولویت‌بندی هوشمند**: پروژه‌ها بر اساس پیشرفت و زمان باقی‌مانده اولویت‌بندی می‌شوند.
- **نمودارهای تحلیلی**: نمایش وضعیت پروژه‌ها به‌صورت نمودارهای دایره‌ای و میله‌ای.
- **مدیریت کامل CRUD**: افزودن، ویرایش، حذف و مشاهده‌ی پروژه‌ها.
- **سبک و کم‌حجم**: بدون وابستگی به کتابخانه‌های سنگین مانند `pandas` و `scikit-learn`.

## 🧩 چالش‌ها (Challenges)

- **دقت پیش‌بینی**: با داده‌های کم، دقت مدل‌ها ممکن است پایین باشد.
- **مدیریت داده‌ها**: ذخیره‌سازی داده‌ها در فایل JSON برای پروژه‌های بزرگ کارایی ندارد.
- **اجرا در Vercel**: توابع Flask در Vercel با محدودیت زمان اجرا مواجه هستند.
- **عدم پشتیبانی از یادگیری عمیق**: به‌دلیل محدودیت منابع، از مدل‌های ساده‌تر استفاده شده است.

## ⚠️ محدودیت‌ها (Limitations)

- **ذخیره‌سازی محلی**: داده‌ها در فایل JSON ذخیره می‌شوند و با هر استقرار مجدد از بین می‌روند.
- **عدم احراز هویت**: همه‌ی کاربران به تمام داده‌ها دسترسی دارند.
- **مقیاس‌پذیری محدود**: برای بیش از ۱۰۰۰ پروژه، عملکرد کاهش می‌یابد.
- **نیاز به بازآموزی مداوم**: مدل‌ها باید با هر تغییر داده مجدداً آموزش ببینند.

## 📋 نیازمندی‌ها (Requirements)

- **Python 3.8+**: برای اجرای بک‌اند.
- **Flask**: برای ایجاد API.
- **numpy**: برای محاسبات عددی.
- **joblib**: برای ذخیره و بارگذاری مدل‌ها.
- **مرورگر مدرن**: برای نمایش فرانت‌اند.

## 🚧 موانع (Obstacles)

- **نصب وابستگی‌ها**: ممکن است در محیط‌های محدود (مانند Termux) نصب کتابخانه‌ها با مشکل مواجه شود.
- **اجرای همزمان بک‌اند و فرانت‌اند**: نیاز به دو پورت متفاوت (۵۰۰۰ و ۳۰۰۰).
- **مدیریت نسخه‌های Python**: ممکن است با نسخه‌های مختلف Python سازگار نباشد.

## 🔧 نیازمندی‌های فنی (Technical Requirements)

- **Python 3.8+**
- **pip**: برای نصب بسته‌ها
- **npm** (اختیاری): برای اجرای فرانت‌اند با http-server
- **Git**: برای کنترل نسخه
